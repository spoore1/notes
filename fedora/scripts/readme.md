switch_theme.sh
===============

Switch between default (light) and dark themes in Gnome.   You can configure a
custom shortcut to easily run the script from a few key strokes.  To do so, 
follow these steps while logged in to a Gnome session:
1. Open Gnome settings
2. Keyboard
3. Keyboard Shortcuts
4. View and customize shortcuts
5. Custom Shortcuts
6. Add Shortcut
   a. Name: "Switch Theme Color Mode"
   b. Command: /path/to/switch_theme.sh
   c. Shortcut: Key-Combo  (e.g. Super+D)
